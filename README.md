# Road to HSK

A Chinese study app covering Integrated Chinese Lessons 1–20 and HSK 1–2: spaced-review flashcards, animated stroke order, handwriting recognition, pinyin typing with tone checking, listening, reading, translation, grammar and quiz practice, a pinyin chart, the 214 radicals, and an English/pinyin/character dictionary. Audio uses the Mandarin voices installed on the computer.

## Layout

- `page.html`: the page and its styles. `tools/build-page.js` wraps it into `index.html` for the desktop app.
- `js/`: the app (`app.js`), pinyin handling and handwriting recognition.
- `data/`: lessons, sentences, grammar, passages, radicals. `data/gen/` is generated by `tools/build-data.js`.
- `main.js`, `preload.js`: the Electron wrapper: tray, streak reminders, automatic updates from this repository's releases.

## Adding a lesson

Edit `data/decks.js`. Lessons confirmed against class slides use `group: "class"`; others use `group: "book"`. Then run `node tools/check-content.js <cedict.txt>`, which checks every pinyin reading against CC-CEDICT and that no sentence uses a word before it's taught.

## Build

```
npm install
sh tools/sync-build.sh
npx electron-builder --win nsis
```

To publish a release that installed copies pick up automatically, bump `version` in `package.json` and `APP_VERSION` in `js/app.js`, then build with `--publish always` and a `GH_TOKEN` that can write to this repository.
