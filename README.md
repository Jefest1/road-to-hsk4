# Road to HSK

A Chinese study app covering Integrated Chinese Lessons 1–20 and HSK 1–2: spaced-review flashcards, animated stroke order, handwriting recognition, pinyin typing with tone checking, listening, reading, translation, grammar and quiz practice, a pinyin chart, the 214 radicals, an English/pinyin/character dictionary, and whole-sentence translation between English and Chinese (with pinyin and a word-by-word breakdown). Audio uses the Mandarin voices installed on the computer.

## Layout

- `page.html`: the page and its styles. `tools/build-page.js` wraps it into `index.html` for the desktop app.
- `js/`: the app (`app.js`), pinyin handling and handwriting recognition.
- `data/`: lessons, sentences, grammar, passages, radicals. `data/gen/` is generated by `tools/build-data.js`.
- `main.js`, `preload.js`: the Electron wrapper: tray, streak reminders, automatic updates from this repository's releases.

## Adding a lesson

Edit `data/decks.js`. Lessons confirmed against class slides use `group: "class"`; others use `group: "book"`. Then run `node tools/check-content.js <cedict.txt>`, which checks every pinyin reading against CC-CEDICT and that no sentence uses a word before it's taught.

## Build

```
npm install
sh tools/sync-build.sh
npx electron-builder --win nsis
```

To publish a release that installed copies pick up automatically, bump `version` in `package.json` and `APP_VERSION` in `js/app.js`, then build with `--publish always` and a `GH_TOKEN` that can write to this repository.

## Sentence translation

Look up → Translate turns a sentence into Chinese or English and shows the pinyin and each word, marking words from the textbook.

- **Windows app, offline (default, free)**: Mozilla's Firefox Translations engine (Bergamot, WebAssembly) and its English→Chinese and Chinese→English models. The user downloads them once (about 127 MB) from Mozilla's server; each file is checked against the SHA-256 in `offline/manifest.json` and stored in the app's data folder. Translation runs in a worker thread in the main process (`offline/`). Pinyin and the word list come from the textbook words first, then CC-CEDICT, split so textbook words win, with the textbook's tone changes for 一 and 不.
- **Windows app, Claude (optional)**: the user's own Anthropic API key in Settings → Translation, stored encrypted with Electron `safeStorage` and used only by the main process. Claude Opus 5.5 (default, with server-side refusal fallback) or Claude Haiku 5.5, effort `low`, JSON schema output. Adds a grammar note, reads pinyin input, and can keep to known words.
- **Web version**: Claude through the artifact's `sample` capability, on the viewer's own Claude account.
- Lesson sentences close to the input are listed in every case.
